# DocuMind AI — RAG Document Assistant

A document question-answering application built using Retrieval-Augmented Generation (RAG).

## Overview

DocuMind AI retrieves relevant information from a company policy document and uses a large language model to generate answers grounded in the retrieved context.

## Tech Stack

- Python
- Sentence Transformers (`all-MiniLM-L6-v2`)
- NumPy
- OpenRouter API
- Streamlit

## Features

- Document loading and text chunking with overlap
- Semantic embeddings and cosine similarity
- Top-3 document retrieval
- LLM-generated answers with chunk references
- Interactive Streamlit interface

## How to Run

1. Clone the repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Create a `.env` file containing:

   `OPENROUTER_API_KEY=your_api_key`

4. Run the application:

   `streamlit run app.py`

## Current Limitations

- Supports one predefined TXT document.
- Uses fixed-length character chunking.
- Source citations are generated by the LLM and are not independently verified.
- Retrieval accuracy has not yet been systematically evaluated.
